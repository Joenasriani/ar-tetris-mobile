# AR Tetris XR

لعبة ألغاز مكانية مفتوحة المصدر من نوع الكتل المتساقطة، مع ثلاثة أهداف نشطة:

- **WebXR AR على الهاتف** — يعمل على المتصفحات/الأجهزة المحمولة التي تدعم WebXR `immersive-ar`
- **Meta Quest / نظارات XR** — WebXR غامر مع وحدات تحكم متتبعة وواجهة داخل العالم الافتراضي
- **Android أصلي** — إصدار مبني بـ Kotlin وJetpack Compose قيد التطوير النشط

بدأ المشروع كلعبة مكانية تعمل في المتصفح. المشغّل الحالي يتطلب WebXR `immersive-ar`؛ وهو يستهدف المتصفحات المحمولة المتوافقة مع AR ويتضمن مسارات XR خاصة بالنظارات، مع إصدار Android أصلي قيد التطوير.

## ما هو موجود حالياً

### WebXR / الواقع المعزز على الهاتف

يحتوي فرع `main` على النسخة المكانية التي تعمل في المتصفح.

تم التحقق من وجود التالي في الكود الحالي:

- عرض ثلاثي الأبعاد باستخدام Three.js
- فحص دعم WebXR immersive-AR
- hit-testing للأرضية ومؤشر تحديد مكان الوضع
- وضع لوحة اللعب فعلياً داخل المساحة المكتشفة
- لوحة 10 × 20
- سبعة أنواع من قطع tetromino
- الحركة، الدوران، hard drop، التثبيت ومسح الصفوف
- النقاط، المستويات ومعاينة القطعة التالية
- تحكم باللمس للأجهزة المحمولة
- حفظ أفضل نتيجة محلياً
- موسيقى وأصوات للعب
- حركة مسح صفوف متوافقة مع XR
- توجد دالة `startFallback3D()` في الكود، لكنها غير متاحة حالياً كخيار تشغيل عادي بدون AR

### Meta Quest / XR

يتضمن نفس كود WebXR سلوكاً خاصاً بالنظارات:

- اكتشاف النظارة / المتصفح
- التعامل مع وحدات التحكم المتتبعة / gamepad
- إدخال وحدات التحكم أثناء الوضع واللعب
- واجهة مقدمة داخل العالم
- واجهة Game Over / إعادة اللعب داخل العالم
- اهتزازات haptic
- وضع اللوحة وإعادة التمركز / إعادة الضبط للـ XR الغامر

### Android أصلي

يحتوي فرع `APK` الافتراضي حالياً على إصدار Android الأصلي المبني باستخدام:

- Kotlin
- Jetpack Compose
- Android DataStore
- minSdk 26
- targetSdk / compileSdk 36

يتضمن إصدار Android حالياً:

- لوحة 10 × 20
- سبع قطع tetromino
- مسح الصفوف
- النقاط والمستويات
- معاينة القطعة التالية
- تحكم باللمس
- إيقاف مؤقت وإعادة اللعب
- حفظ أفضل نتيجة محلياً
- إعداد Google Play release bundle

> اسم الفرع الافتراضي حالياً هو `APK`، لكنه يحتوي على الكود المصدري وليس ملف APK مترجماً.

## اتجاه المشروع

الهدف ليس استبدال منصة بأخرى.

الهدف هو تطوير نفس اللعبة عبر:

**الويب على الهاتف / AR → Meta Quest / XR غامر → Android أصلي**

يمكن للمساهمين العمل على منصة واحدة أو على توحيد سلوك اللعب بين الإصدارات.

## مجالات المساهمة

### WebXR / AR على الهاتف
- ثبات الوضع واكتشاف الأرضية
- توافق متصفحات الهاتف
- اللمس والإيماءات
- أداء Three.js
- دورة حياة جلسة XR
- وضع fallback
- التسجيل / الوسائط
- تحسين الواجهة المكانية

### Meta Quest / XR
- تعيين أزرار التحكم
- تجربة استخدام خاصة بالنظارات
- وضوح الواجهة داخل العالم
- مسار إعادة اللعب / إعادة التمركز
- haptics
- الأداء في الجلسات الغامرة
- اختبارات خاصة بالأجهزة

### Android
- فصل محرك اللعبة عن `MainActivity.kt`
- اختبارات وحدات deterministic
- استجابة اللمس
- QA لدورة الحياة والحفظ
- سهولة الوصول
- الأداء وتغطية الأجهزة
- أوضاع لعب جديدة

راجع `ROADMAP.md` و`ARCHITECTURE.md` و`CONTRIBUTING.md`.

## الفروع

- `main` — إصدار WebXR / AR على الهاتف / Meta Quest
- `APK` — إصدار Android الأصلي والفرع الافتراضي الحالي
- الفروع التاريخية محفوظة كسجل للتطوير

## تشغيل إصدار WebXR

يتطلب الواقع المعزز الغامر اتصال HTTPS آمن.

نقطة الدخول الرئيسية:

```text
index.html
```

يستخدم البناء Three.js عبر import map، وملفات صوت محلية داخل `music/`.

## بناء إصدار Android

المتطلبات:

- JDK 17
- Android SDK متوافق مع API 36
- Gradle متوافق مع إعدادات المشروع

Debug build:

```bash
gradle :app:assembleDebug
```

Release bundle:

```bash
gradle :app:bundleRelease
```

راجع `PLAYSTORE_RELEASE.md` لمعلومات التوقيع والنشر على Play.
